# Human-in-the-Loop Evaluation Best Practices

When programmatic verifiers are insufficient:
- **Cohen's Kappa:** Ensure inter-annotator agreement exceeds kappa > 0.80.
- **Blinded Grading:** Mask model identities and provider prompts from evaluators.
- **Detailed Rubrics:** Provide granular 5-point Likert scales with explicit behavioral anchors.
