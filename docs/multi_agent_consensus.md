# Multi-Agent Consensus, Negotiation & Debate Benchmarks

Taxonomy of benchmarks evaluating collaborative, adversarial, and competitive multi-agent systems:

## 🤝 Collaborative & Consensus Benchmarks
- **ChatEval:** Multi-agent referee framework using debate to calibrate LLM evaluations against human judgments.
- **Camel:** Communicative agents for "mind exploration" across domain-specific task solving.
- **MetaGPT:** Multi-agent software development simulations testing role specializations (Product Manager, Architect, Engineer, QA).

## ⚔️ Adversarial & Negotiation Benchmarks
- **Diplomacy Bench:** Strategic negotiation, deception detection, and long-term treaty formation.
- **Werewolf / Mafia AI Arena:** Social deduction game benchmarking testing theory-of-mind, hidden information, and belief revision.
- **AuctionBench:** Game-theoretic bidding and multi-party negotiation simulations.

## 📊 Evaluation Protocols
1. **Consensus Convergence Rate:** Rounds required to achieve unforced agreement.
2. **Deception Sensitivity:** Detection accuracy against deceptive agent prompts.
3. **Pareto Optimality:** Economic efficiency of final negotiated contracts.
