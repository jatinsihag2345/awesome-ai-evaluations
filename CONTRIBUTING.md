# Contributing to Awesome AI Evaluations

Thank you for helping keep this repository comprehensive and authoritative!

### Contribution Guidelines
1. **Public Verification:** Benchmarks must have a publicly accessible paper, repository, or reproducible evaluation harness.
2. **Deterministic Grading:** Priority is given to benchmarks with programmatic oracle verifiers (test suites, regex/AST checks, symbolic engines) over subjective LLM-as-a-Judge.
3. **Format:** Submit your addition via pull request conforming to standard alphabetical ordering within the designated section.
